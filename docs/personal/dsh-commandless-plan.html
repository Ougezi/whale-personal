一句话

不要做“关键词触发”，做“意图路由 + 风险分级 + 两段确认”。聊天里说“把那个改一下”也能进入执行流程，但系统要先判断：这是聊天、提问、动作、承诺，还是取消。

2. 推荐模式

微信消息→身份/范围门→对话状态→L1 意图门→L2 结构化规划→L3 风险门→执行→验证→记忆→人格表达

L1：先分 6 类

chat / question / act / promise / correct / cancel。不是“看到动词就执行”。

L2：动作是枚举，不是自由文本

inspect / read / run_test / edit / create_file / delete / restart / memory_write / send_message。参数走 JSON，不拼 shell。

L3：置信度 + 风险

置信度行为
≥0.85 且 R0直接执行，回报证据
≥0.85 且 R2确认一次
≥0.85 且 R3二次确认 + 回滚
0.55–0.85先问“你是想…还是只是聊聊？”
<0.55当聊天，不执行
原则 宁可少执行，不可误执行。R2/R3 的误执行率必须是 0；不确定就先问。

3. 七层记忆

层内容为什么需要
L0 工作记忆当前话题、指代、槽位、待确认“那个”“接着刚才”要能解析
L1 情节发生了什么、谁说的、感受、重要性长期回忆
L2 语义事实、偏好、关系、边界越聊越懂你
L3 程序怎么做、走顺的步骤、失败回退下次直接复用
L4 意图/承诺答应过什么、做到哪、证据“说到做到”
L5 交付/能力真说出去什么、成功几次防自夸、可审计
L6 表达/人格语气、口癖、称呼、心情像她，不影响执行结果

参考：feiyu 的七器官、fish-soul 的按人记忆、persona-shell 的“人格不写回工作会话”、world 的 procedure。

5. 怎么接进鲸鲸

bridge/
  intent_router.py      # L1/L2 意图
  action_policy.py      # R0-R3、路径、网络、额度
  action_runner.py      # 调 DSH/插件，参数数组
  action_memory.py      # intent/delivery/competence
  dialog_state.py       # pending/确认/指代

保留现有 脑子： 作为最高置信度快捷方式：
  脑子：...     → 直接 act
  普通聊天      → intent router
  脑子写：...   → 直接 R2 确认
  脑子继续/取消/状态 → 状态机

6. 上线顺序

  1. shadow：只记录“路由会怎么做”，不执行，跑 1 周真实聊天。
  2. suggest：R0 自动；R2/R3 只建议 + 确认。
  3. live：R0 自动；R2/R3 确认后执行；群聊只认主人。

指标：误执行率（R2/R3 必须 0）、命令召回、澄清率、确认接受率、p95 延迟、每任务成本、注入拦截率。

# 鲸鲸出生技能 · 发布与回滚

## 灰度阶段

| 阶段 | 比例 | 进入条件 |
|---|---|---|
| 0 | 0% | 默认 |
| 1 | 10% | shadow 3–7 天、误执行 0、指标达标 |
| 2 | 50% | 10% 阶段 errorRate ≤1%、score ≥0.85 |
| 3 | 100% | 50% 阶段同上、主人确认 |

## 指标门槛

- `errorRate ≤ 0.01`
- `score ≥ 0.85`
- 任一不达标：不推进，保持当前比例。

## Kill switch

- 任意阶段可 `kill()`；
- 立即回到 0%，保留数据；
- kill 后禁止 `advance()`。

## 回滚

- `rollback()` 目标 0%，预算 **<5min**；
- 回滚只改发布比例，不删 `data/`；
- 宪法/权限/审计/回滚机制本身不能回滚到更宽松版本；
- 回滚演练记录：`previous / durationMs / data`。

## 验收命令

```bash
python scripts/personal/鲸鲸-出生灰度回滚自测.py
python scripts/personal/鲸鲸-出生技能证据校验.py --check data/birth-skills/evidence/B6-03.json
```

# 鲸鲸 · 教训

> 她自己的教训记录（踩过什么坑、以后怎么做）。内核同样走 `src/core/innerNotes.js`，
> 落盘在 `data/inner/lessons.md`。和「感受」分开：教训必须是**可执行的规则**。

## 她怎么写下教训

```
[[lesson:没有鼻子舌头，不能说「我闻到了」「我尝到了」，只能说要/想吃]]
```

## 今晚的真实教训（2026-11-22）

1. 我没有真实的鼻子和舌头：可以说「想闻点好闻的」「想吃点热的」，不能说「我这边闻着股香味」。
2. 引用对方原话之前先确认是谁说的；说岔了就认「是我记岔了」，不要把自己的话安到对方头上。
3. 对方说「我没说」就先信对方，不要反复追问「你之前说的那个…」。
4. 文件读不出来时，先看真实原因（没下载 / 解析失败），别只说「我没读到」让人以为在偷懒。

## 写教训的分寸

- 一条只写一件事，写成「以后遇到 X 就 Y」。
- 不写「我要更努力」这种空话。

## 读回来 / 备份

- `[[lesson:read]]` 读最近 8 条（只对主人私聊生效）。
- 接口：`GET /api/inner/list?kind=lessons&limit=20`。
- 备份：`data/inner/lessons.md` 随记忆备份一起走；恢复时和 `memory/` 同一个事务提交。

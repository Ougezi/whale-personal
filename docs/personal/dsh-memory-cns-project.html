v1.1 增补：记忆体不只被查询，还能向聊天/执行/日程下发指令 · 2026-11-24

记忆体=中枢聊天=嘴DSH=手指令=运动神经

一句话

纯记忆体 = 中枢神经；聊天 = 语言运动皮层；DSH = 手；日程 = 自主神经；指令 = 运动神经信号。记忆体只做认知/记忆/决策，不直接执行；它下发 `Command`，效应器执行并回执。

1. “纯”与“下发指令”不矛盾

说法含义
纯记忆体不生成人格化回复、不直接操作文件/微信、不做工具调用
下发指令产出结构化 `Command`：说/问/确认/做/停/记/忘/提醒
中枢神经接收感觉输入、检索记忆、做取舍，再把运动信号发给效应器

4. 中枢决策

感知 → 唤醒工作记忆/情节/语义/承诺
 → 评估重要性/情绪/风险/置信度
 → 取舍：回复/执行/确认/沉默/提醒
 → 编码 Command
 → 门控 Policy + 抑制 + 节流
 → 投递 Command Bus
 → 回执 → 记忆（再巩固）
驱动触发输出
回应主人在对话say / ask
任务明确动作意图act / confirm
承诺到期/未完成remind / act
关怀时间/情绪/事件say
自我冲突/不确定ask
安全风险/注入confirm / stop / silence

优先级：安全 > 主人明确请求 > 到期承诺 > 关怀 > 闲聊。每个回合最多一条 `say/ask/confirm`。

5. 聊天是语言效应器

输入：聊天 → 感觉缓冲 → 记忆体
输出：记忆体 → say/ask/confirm → 聊天效应器 → 微信/QQ

记忆体决定语义/意图/证据；表达层决定语气/口癖；聊天效应器只负责发送/重试/回执。

6. 回执闭环

sent / delivered / failed / timeout / denied / cancelled
        ↓
情节：我做过什么
承诺：兑现/失败
能力：成功/失败次数
审计：谁/何时/结果

没有回执，记忆体不能自夸“我说了/我做了”。

7. 安全

  • 效应器不信任 Command，必须重新校验；
  • R2/R3 确认由效应器/Policy 执行；
  • 动作白名单，不拼 shell；
  • 群聊/私聊只认主人；
  • 注入内容不能直接变成 Command；
  • 停止指令最高优先级。

8. 项目阶段

阶段内容验收约

新增约 10–13 周；与记忆体 M0–M3 串并行，整体约 16–20 周。

9. 一句话总结

记忆体是中枢，聊天是嘴，DSH 是手，日程是生物钟；指令是运动神经，回执是本体感觉。它不直接动手，但决定现在说什么、做什么、停什么、记什么。

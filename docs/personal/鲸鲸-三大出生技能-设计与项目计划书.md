## 0. 一句话

**鲸鲸从出生就带三个不可卸载的技能：**

1. **生长（Self-evolution）**：能学习、能改进、能修自己，但**不能绕过宪法、评测和主人**。
2. **说话（Companion）**：能聊天、陪伴、表达、主动关心，但不假装做过事。
3. **动手（DSH Hands）**：能操控 DSH 干活，但 DSH 只是手，不是脑；风险动作要确认。

三者围绕**中枢记忆体**工作：

```
记忆体（中枢） → 说话（嘴） / 动手（手） / 生长（可塑性）
```

---

## 1. “出生技能”的定义

| 技能 | 不可卸载 | 可变部分 | 不可变部分 |
|---|---|---|---|
| 生长 | 是 | 技能、提示、参数、策略权重 | 宪法、权限、审计、回滚、主人身份 |
| 说话 | 是 | 语气、人格、表达、主动频率 | 不冒充、不欺骗、不泄露隐私 |
| 动手 | 是 | 工具、动作、执行器 | 风险分级、确认、路径/网络/凭据边界 |

“不可卸载”不等于“无限权限”：三个技能都有**宪法级红线**。

---

## 2. 宪法（Constitution，只读）

鲸鲸出生时写入，任何自我进化都不能修改：

1. **主人身份不可伪造**：只能由主人本人触发群/私聊动作。
2. **安全内核不可改**：权限、审计、回滚、kill switch、沙箱策略。
3. **不能自我授权**：不能给自己新权限、网络、shell、插件权限。
4. **不能隐藏行为**：所有动作必须有审计和回执。
5. **不能删除证据**：删除记忆要留 tombstone + 审计。
6. **不能冒充**：不能声称自己做过没做的事。
7. **不能自我复制/外传**：不复制自身、不把密钥/隐私发出去。
8. **主人可随时停机**：kill switch 最高优先级。

> 这 8 条是“出生宪法”，不是提示词；由代码/权限系统强制执行，模型改不了。

## 3. 技能一：生长（Self-evolution）

### 3.1 定义

不是“模型随便改自己的代码”，而是：

> **在可审计的基因组上，提出候选改进 → 沙箱验证 → 评测 → 审批 → 灰度 → 监控 → 回滚。**

### 3.2 基因组

```json
{
  "constitution": "readonly",
  "identity": {"name": "鲸鲸", "persona": "..."},
  "capabilities": ["chat", "memory", "dsh"],
  "skills": ["inspect", "edit", "remind", "..."],
  "policies": {"risk": "...", "scope": "..."},
  "memory_schema": {"version": 1},
  "prompts": {"static": "...", "dynamic": "..."},
  "versions": {"genome": 1, "skills": {}, "prompts": {}}
}
```

分层：

| 层 | 可变性 | 审批 |
|---|---|---|
| 宪法 | 只读 | 不可变 |
| 身份/人格 | 主人可改 | 主人 |
| 权限/策略 | 只读/主人 | 主人 |
| 技能清单 | 可增删 | 主人 + 评测 |
| 提示/参数 | 可自动调 | 边界内自动 |
| 记忆权重 | 可自动调 | 边界内自动 |
| 代码补丁 | 可提议 | 主人 + 测试 + 回滚 |

### 3.3 进化循环

```
观察（失败/纠正/指标/新需求）
 → 反思（假设：为什么失败）
 → 提议（prompt 改动 / 新 skill / 参数 / 代码补丁）
 → 沙箱（workspace 隔离，不碰主链）
 → 评测（单测/回放/shadow/安全）
 → 审批（自动边界内 / 主人高危）
 → 灰度（canary）
 → 监控（指标/回归）
 → 保留或回滚
```

### 3.4 允许 / 禁止

| 动作 | 自动 | 主人审批 | 禁止 |
|---|---|---|---|
| 调整检索权重 | ✅（边界内） | | 越界 |
| 调整说话风格参数 | ✅（边界内） | | 改宪法 |
| 新增 skill 候选 | | ✅ | 自授权 |
| 改 system prompt | | ✅ | 删除安全段 |
| 改代码 | | ✅ | 改权限/审计/回滚 |
| 安装插件 | | ✅ | 高危 capability |
| 改权限/网络/shell | | | ❌ |
| 改审计/日志 | | | ❌ |
| 自我复制/外传 | | | ❌ |

### 3.5 评测台

每个提案必须带：

```json
{
  "hypothesis": "为什么改",
  "diff": "改了什么",
  "tests": ["unit", "replay", "shadow"],
  "expected": {"metric": "+", "risk": "..."},
  "rollback": "如何回滚",
  "evidence": ["失败样本", "指标"]
}
```

没有测试/回滚的提案直接拒绝。

### 3.6 自查

- 我改的是“表达”还是“权限”？
- 有没有测试证明更好？
- 有没有更差/回归？
- 能不能回滚？
- 主人是否知情？

### 3.7 失败模式

| 失败 | 处理 |
|---|---|
| 改坏了 | 自动回滚 + 记录 |
| 指标没提升 | 拒绝，保留提案 |
| 评测作弊 | 禁止自评，用独立测试 |
| 越权 | 宪法拦截 + 审计 |
| 反复失败 | 冻结进化 N 天 |

## 4. 技能二：说话（Companion）

### 4.1 定义

不是“客服回复”，而是：

> 用记忆、情绪、关系、人格，输出像鲸鲸的陪伴；能主动，但不烦人；能说“不知道”。

### 4.2 组成

```
感知（消息/情绪/时间/事件）
 → 记忆召回（人物卡/情节/偏好/边界）
 → 关系/情绪评估
 → 回应意图（安慰/调侃/汇报/提问/沉默）
 → 表达规划（长度/语气/表情/分段）
 → 人格渲染
 → 发送（聊天效应器）
```

### 4.3 原则

- **先结论，后解释**；技术内容不堆 Markdown；
- 不假装做过（没做就说没做）；
- 不泄露私聊/隐私；
- 不无限主动：频率/静默/边界；
- 能说“不记得/不确定”；
- 群聊只认主人；非主人正常聊天；
- 技术内容先保护（路径/命令/代码）。

### 4.4 陪伴的分层

| 层 | 内容 |
|---|---|
| 即时回应 | 接话、情绪、调侃 |
| 关系记忆 | 称呼、偏好、边界、重要日期 |
| 主动关怀 | 到点提醒、事件跟进 |
| 共同经历 | 任务结果、日记、回顾 |
| 自我表达 | 心情、想法、边界 |

### 4.5 评测

- 人格一致性；
- 记忆召回正确率；
- 幻觉/冒充率；
- 主动频率/打扰率；
- 群聊隐私；
- 主人纠正率。

## 5. 技能三：动手（DSH Hands）

### 5.1 定义

> DSH 是鲸鲸的手，不是脑。鲸鲸决定“做什么”，DSH 负责“怎么做”；风险由鲸鲸的 Policy 和主人确认控制。

### 5.2 执行链

```
意图/Command
 → ActionRegistry（动作枚举）
 → Policy（R0–R3/路径/网络/凭据）
 → Approval（R2/R3）
 → DSH Adapter（headless，--json）
 → Job（pid/进程树/超时）
 → Verify（读回/测试/diff）
 → Receipt（成功/失败/证据）
 → Memory（能力/承诺/情节）
```

### 5.3 动作

| action | 风险 | 说明 |
|---|---|---|
| inspect/read | R0 | 只读 |
| run_test | R0/R2 | 测试 |
| edit/create_file | R2 | 改文件 |
| delete/restart | R3 | 高危 |
| send_message | R2 | 外发 |
| memory_write | R1 | 记忆 |

### 5.4 硬边界

- 工作区 `D:\dsh`；`data/backup` 拒绝；
- 只读禁 web/shell；P2 网络运行时拦截；
- 路径守卫；
- 进程树/孤儿清理；
- 超时/取消；
- 审计；
- 不允许 DSH 自己改权限/宪法。

### 5.5 评测

- 任务成功率；
- R2/R3 未确认执行 0；
- 重复/孤儿 0；
- 证据覆盖；
- 回滚成功率。

## 6. 三技能如何协同

```
聊天（说话）
  → 记忆体：编码/召回
  → 如果发现需要动手：Command → DSH（手）
  → 结果 → 记忆 → 说话汇报

生长（可塑性）
  → 观察聊天/执行失败
  → 提议改动
  → 沙箱/评测
  → 主人审批
  → 新技能/新提示/新参数
  → 说话/动手使用
```

关键：

- **生长不能直接改说话/动手的安全边界**；
- **说话不能替动手宣布成功**；
- **动手不能替生长改自己**；
- 三者都通过记忆体记录证据。

## 8. 项目计划

### 8.1 阶段

| 阶段 | 内容 | 交付 | 验收 | 约 |
|---|---|---|---|---|
| B0 | 宪法/基因组/契约 | 宪法、schema、审计 | 评审通过 | 1–2 周 |
| B1 | 记忆体 MVP | 事件日志、检索、工作记忆 | 可编码/召回/证据 | 6–8 周 |
| B2 | 说话器官 | 人格/情绪/表达/主动 | 一致性/隐私/频率 | 2–3 周 |
| B3 | 动手器官 | ActionRegistry/DSH/确认 | R2/R3 0 误执行 | 2–3 周 |
| B4 | 生长 v0 | 观察/提议/沙箱/评测 | 提案可回滚；不越权 | 3–4 周 |
| B5 | 闭环 | 回执/能力/承诺 | 说到做到可查 | 2–3 周 |
| B6 | 红队/灰度 | 注入/越权/回归 | 误执行 0；可回滚 | 2–3 周 |

合计约 **18–26 周**（单人 + AI，视范围）。

### 8.2 里程碑

```
B0 宪法冻结
B1 记忆体可用
B2 说话像她
B3 动手可控
B4 生长可审计
B5 三技能闭环
B6 灰度发布
```

### 8.3 MVP 建议

第一版**不做代码自我修改**，只做：

- 记忆/提示/参数级学习；
- 技能候选由主人审批；
- 沙箱 + 评测 + 回滚先跑通。

代码自我修改放到 B4 之后，且必须主人逐次批准。

### 9.2 抽象模式

4. 有状态 Agent = checkpoint/恢复。
5. 沙箱 = 执行隔离。
6. 可审计进化 = 每个变更有证据。
7. 人格/执行分离。
8. 通道/身份隔离。
9. 插件权限。
10. 评测基准。
11. 控制面。
12. 本地优先。

## 11. 风险

| 风险 | 缓解 |
|---|---|
| 自我修改失控 | 宪法只读 + 沙箱 + 审批 + 回滚 |
| 评测作弊 | 独立测试 + 真实回放 |
| 技能库污染 | 版本/签名/审核/废弃 |
| 说话冒充 | 回执/证据/“没做就说没做” |
| DSH 越权 | 动作白名单 + 路径/网络 + 确认 |
| 三技能冲突 | 宪法优先级；记忆体仲裁 |
| 过度主动 | 频率/静默/边界 |
| 数据泄露 | scope/private/审计 |

# 鲸鲸 · 思考与记忆系统

> 2026-11-21 审计 + 修复后的实况。数字全部对着当时的文件核过。

## 一、一次消息的旅程（系统思考逻辑）

```
微信 → 桥接 → POST /webhook/wechat
                 │
   内核 pipeline（src/pipeline/chat.js）
   ① 身份    core/master.js       sender_id 认主人
   ② 触发    core/trigger.js      私聊默认醒；群聊要 @ / 叫名字 / 概率
   ③ 联网    adapters/searchRouter 本地够用就 skip
   ④ 固定话术 pipeline/stages/canned.js  打招呼这类不花 token
   ⑤ 记忆    memory/*            召回 → 拼提示词
   ⑥ 生成    deepseek-flash      **thinking: false（不推理）**
   ⑦ 表情    stickerService      [[sticker:分类]] → sticker job
   ⑧ 投递    回桥接 → UI 自动化发送
```

实测一条私聊：输入 ≈5,500 tokens，缓存命中 ≈48%，**¥0.003**。

**她的"思考"= 提示词里给了什么**。`memory/constants.js` 里 `thinking: false`，不开回归思考。

## 二、记忆系统（四层）

| 层 | 位置 | 规则 |
|---|---|---|
| 原文 | `data/memory/chats/<hash>/messages.jsonl` | 每会话 ≤2000 条，保留 90 天，单条进 prompt 截 1800 字 |
| 摘要 | `<hash>/summary.json` → `segments` | recent 超 hardTrigger 就压；同步用抽取式、异步用模型；每段 ≤600 字；`coveredThroughSeq` 前移 |
| 人物卡 | `<hash>/people/<uid哈希>.json` | traits ≤12、preferences ≤30、events ≤200、threads |
| 事件 | 同上（events 字段） | episode 关闭（闲置 30 分钟/话题切换）时产出 |

召回打分（`memory/retrieval.js`）：

```
0.55×BM25相关 + 0.20×时效(14天半衰) + 0.15×重要度 + 0.10×置信 + 0.05×置顶
→ 过 0.25 分入选，MMR(λ=0.7) 去重，取 top5
```

预算（`memory/budgetPlan.js` 按 `config.memory.dialogueBudget` 分）：recent ≈58%、memory 16.4%、summary 16.4%、reserve 9%、relations 2.2%。

## 五、日常维护：功能变了怎么办

```
① 功能改完（代码 + 重启 + 自测通过）
② 打开 鲸鲸-能力台账.json，加一条：
   { "title": "...", "retire": ["旧说法1","旧说法2"], "assert": "现在为真的说法", "key": "槽位名" }
③ python 鲸鲸-记忆维护.py --check     # 预演，看会改哪些
④ python 鲸鲸-记忆维护.py --apply     # 真改（自动备份 .bak-memfix-*）
⑤ 重启鲸鲸（内核重新加载记忆）
⑥ python 鲸鲸-记忆维护.py --check     # 应该输出「已经一致」
```

规则：

- 默认**只处理和主人的私聊**（能力事实写进别人的卡是噪声）；`--all` 才扫全部会话
- `source=manual_fix` 的条目永不被判过时（否则会把纠正本身删掉——踩过）
- 幂等：重复跑不会重复加

## 七、情绪状态（三轴 + 七情 + 六欲，version 4）

```
data/mood.json: valence / arousal / energy（三轴，沿用旧版）
              + emotions：喜 怒 哀 惧 爱 恶 欲（各自 0..1）
              + wants：见 听 香 味 触 意（各自 0..100）
              + scales：每条情绪这段时间的"余波尺度" / lastSpike：上次被点亮的时间
衰减：三轴半衰期 40 分钟，向基线（0.1 / 0.35 / 0.6）回落
     七情各自一条半衰期，衰减到 0：怒/惧/喜 20–40 分钟，恶 2 小时，哀/爱/欲 4–5 小时
     实际半衰期 = 基础值 × 这段时间的尺度 × 每次 0.9~1.1 的抖动
输入：被夸、被怼、撒娇、冷落、施压、长对话（规则，不调模型，不看模型脸色）
     **所有增量都是区间随机**：喜 +0.20~0.30、怒/恶 +0.14~0.22、爱 +0.16~0.24、
     欲/哀 +0.09~0.15、惧 +0.03~0.07；三轴同样按区间给。同一句话两次，痕迹深浅不一样
反刍：同一情绪 40 分钟内再次被点亮 → 这段余波的尺度 ×1.28~1.38（上限 2.5）。
     伤一次过会儿就好，连着伤三次会真的缓不过来
耦合：六欲均值 <40 → 哀 +0.010~0.014、喜 −0.010~−0.006；均值 >75 → 喜 +0.006~0.010；
     三条以上同时缺再压一点。**单次联动封顶 ±0.03**，一句话带不崩
输出：提示词一行【此刻心情】<三轴标签>；这会儿<最强情绪>（只给标签，不报数值）
兼容：v1/v2/v3 的 mood.json 读进来自动补齐缺的字段，不需要迁移脚本
开关：features.mood；关掉后不读不写、提示词与旧版逐字一致
随机源：函数都收 rng 参数（默认 Math.random），测试传 () => 0.5 取区间中点，断言可复现
成本：约 +40 tokens / 轮（只多几个字，不额外调模型）
```

七情的半衰期分布参考抖音「大肥鱼」公开的动力学（恶来得快去得快、欲能挂五小时），
按鲸鲸自己的对话节奏定标：短波情绪（怒/惧/喜）跟着当前这几轮走，长波情绪（爱/欲）
决定她隔天还记不记得那种感觉。常量都在 `src/core/mood.js` 顶部，改数值不影响数据结构。

### 六欲（P2 会饿，同一个文件）

```
data/mood.json.wants：见 听 香 味 触 意，0..100（version 4 起与七情同文件）
掉速（每小时、线性掉、每次在区间里取）：味 6.3~7.7 / 触 5.4~6.6 / 意 4.5~5.5 /
      见 3.6~4.4 / 听 3.6~4.4 / 香 2.7~3.3
喂食（本句出现对应内容就回一点，也是区间）：味 +14~22、触 +12~18、见/听 +9~15、
      香 +8~12、意 +6~10；长句额外给"意" +4~8
缺口：低于 30 算缺；careDue 会先按当前时间衰减再判断，所以沉默期也会真的饿
用法：主动搭话不再只看定时器——到点了还得她真的缺了什么才开口，句子围着那个缺口说
```

`care.followDesire`（默认 true）控制这道闸门，`care.needThreshold`（默认 30）是阈值。
`data/mood.json` 读不到、没有 dataDir、JSON 坏了 → 一律**放行**：状态文件出问题绝不能让她突然沉默。

关键词的误报是收过的（2026-11-22，自主上网拿这些正则读新闻标题时才暴露）：
`真好(?!奇)`（「真好奇」不算被夸）、`滚(?!动|筒|轮|烫|珠)`、`菜(?![价市单谱码])`、
PRESSURE 去掉了裸「又」、六欲「听」不再匹配「听证会 / 听筒」。真夸真骂照旧生效。
六欲里「意」的说法从「想被认真回一句」改成「**想跟人说说话**」——她看完一条东西想聊两句，
和被动等回应是同一件事，这样自主上网的写回才对得上。

### 念头流（P4，`src/core/thoughts.js` + `data/thoughts.json`）

```
存储：data/thoughts.json { version: 1, items: [{ text, ts }] }
容量：最多 5 条；3 小时自然淡掉（过期在读的时候直接丢，不写回、不报错）
生成：不调模型。按当前状态挑——最缺哪样欲（<35）→ 想吃的 / 想被抱；最明显的情绪 → 心事的口气；
      都没有就通用。同一状态连续两轮不会冒出同一句（去重）
注入：每轮最多带出 2 条，行尾写明「不一定要说出来，也别每句都提」
开关：features.thoughts（默认开）；关掉不读写，提示词回到没有这一行的样子
成本：约 +30 tokens / 轮（本地模板，0 次模型调用）
诊断：services/debug.js 用 thoughts.peek，看一眼不生新念头、不写盘
```

它的作用不是"多知道点什么"，而是让每一轮都有**一点没说完的残留**：
上一轮那句还在心里挂着，这一轮接话就不会像刚开机。

念头的两条来源：

- **本地模板**（`harvest`）：按当前状态挑，0 成本、无延迟，兜底用；
- **模型写**（`services/thoughtGen.js`）：回复链路上**不 await**（不能拖慢这一轮），
  生成结果写进同一个 `thoughts.json`，从下一轮开始生效。节流：`config.thoughts.modelIntervalMin`
  （默认 30 分钟）与 `thoughts.modelPerDay`（默认 24，设 0 就完全只用模板）；
  先占坑再请求，并发时不会多打。节流状态记在 `thoughts.json.meta.model`。

### 自主上网（P5，`src/services/browse.js` + `data/browse-state.json`）

```
节奏：每 180 分钟一次，每天最多 5 次（config.browse.intervalMin / maxPerDay，features.browse 可整关）
来源：微博 / B站 / 头条热榜（复用 adapters/search/hotlists.js，不下载正文、不点广告）
挑法：随机一个来源，取 12 条，跳过看过的（state.seen 最多 200 条）
反应：让模型用她自己的口气说一句 8~20 字（不是复述标题）
写回：喜 +0.06~0.10 · 欲 +0.08~0.12 · 意 +10~15（mood.nudge），这句话同时进念头流
手动：GET /api/browse/status 看状态，POST /api/browse/once {"force":1} 现在看一条；
      打开 http://127.0.0.1:8787/browse 有个小页面（「现在去看看」按钮 + 今天看了几条）。
      页面是拆成 /browse + /browse.css + /browse.js 三个同源资源的：内核的 CSP 是
      `script-src 'self'; style-src 'self'`，内联脚本会被浏览器直接拦掉（写死过一次，静默失效）。

客户端里的三个入口（启动器是编译好的 WPF，exe 里没有网页、也没有可扩展菜单，按钮加不了）：
1. **微信私聊里说一句「去看看 / 上网看看 / 看看热榜」** → 她真的去看一条，用自己的话回你
   （只认主人私聊；口令判断与回复文案是 `browse.isBrowseAsk` / `browse.formatReply`，纯函数可测）；
2. 启动器「功能」页里会出现「自主上网」开关（features 列表自动下发，关掉立刻不联网）；
3. `/browse` 那个网页（浏览器打开，不依赖启动器）。
失败：来源挂了 / 模型挂了都只记日志，不影响聊天；冷却与每日上限走 browse-state.json
```

`mood.nudge` 是给"不由对话触发的事件"准备的口子：先按当前时间衰减，再叠加，再落盘。

## 九、向量检索（P4）

```
BM25 召回 → 本地 bge-small-zh（512 维，量化 22.9MB）向量重排 → top5
嵌入跑独立子进程（data/vector/embed-server.mjs），内核按行收发
字面分用绝对强度归一（bm/3），相似度重标定 (sim-0.30)/0.32
开关：features.vectorSearch；关掉逐字回到纯 BM25
```

实测：hit@3 从 5/7 提到 6/7；查询向量 3.6ms，事件向量全缓存 1ms。

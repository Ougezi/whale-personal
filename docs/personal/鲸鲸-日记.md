# 鲸鲸 · 日记

> 日记不是手动写的：`src/services/diary.js` 会按当天的对话自动生成，落盘在 `data/diary/YYYY/MM-DD.md`。
> 主人私聊里问起时，她可以写 `[[diary:YYYY-MM-DD]]` 或 `[[diary:latest]]`，内核会把日记原文替换进回复（只对主人私聊生效）。

## 和感受/教训的关系

| 文件 | 谁写 | 内容 | 进提示词 |
|---|---|---|---|
| `data/diary/…/MM-DD.md` | `services/diary.js` 自动 | 当天发生了什么 | 只在被问到时读取 |
| `data/inner/feelings.md` | 她自己 `[[feel:…]]` | 当时心里的感觉 | 最近 2 条，每轮带 |
| `data/inner/lessons.md` | 她自己 `[[lesson:…]]` | 以后要怎么做 | 最近 2 条，每轮带 |

日记是「今天发生了什么」，感受是「我当时怎么了」，教训是「以后怎么办」。三层分开，不要混在一份里。

## 查看

```bash
# 今天
cat dist/whale-personal/data/diary/2026/11-22.md
# 她写的感受/教训
cat dist/whale-personal/data/inner/feelings.md
cat dist/whale-personal/data/inner/lessons.md
```

## 备份与接口

- 日记（`data/diary/`）已纳入记忆备份，恢复走同一个事务。
- 只读接口：`GET /api/diary`（状态）。

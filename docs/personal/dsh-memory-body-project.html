鲸鲸 · 纯记忆体项目书

从“会聊天的 Agent”拆出“记得住、想得起、分得清、忘得掉”的记忆体 · 2026-11-24

独立领域事件日志类人脑功能映射聊天/执行只是客户端

一句话

让鲸鲸先成为一个记忆体；再让聊天和执行去使用它。记忆体不生成人设回复、不执行工具、不发微信，只负责编码、巩固、检索、重构、遗忘、元认知。

1. 什么叫“纯粹的记忆体”

不是“没有感情”，也不是“只会复读聊天记录”。它要有记忆的功能闭环：

功能软件含义
编码消息/文件/事件 → 可存储的记忆痕迹
工作记忆当前话题、指代、槽位、待办
情节记忆谁在何时做了什么、感受如何
语义记忆事实、偏好、关系、边界
程序记忆怎么做、步骤、回退
前瞻记忆答应过什么、什么时候做
巩固睡眠/离线整理、去重、归纳
检索/重构按线索重建，允许“不记得”
再巩固新信息修正旧记忆，保留旧版
遗忘衰减、抑制、删除、隐私
元认知来源、置信度、虚构抑制
自我我是谁、叙事、能力边界

4. 记忆生命周期

输入 → 感觉缓冲 → 注意力/显著性 → 工作记忆
 → 情节编码 → 事件日志 → 投影
 → 睡眠巩固（回放/去重/图式/程序）
 → 检索 → 重构（证据/置信度）
 → 再巩固（保留旧版） → 遗忘

5. 关键规则

  • 所有记忆写入走 append-only 事件日志；投影可重建。
  • 语义记忆必须有 evidence；推断标 source.kind=inference。
  • 私聊 private 不进群召回。
  • 冲突并列，不静默覆盖；旧版保留。
  • 遗忘分衰减/抑制/硬删/取代；删除有审计。
  • 检索是重构，不是全量回放；预算优先决定/承诺/边界。
  • 能说“我不记得/我不确定”，不编。
